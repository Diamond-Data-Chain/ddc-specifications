# Changelog

All notable changes to the Diamond Data Chain Specifications repository will be documented in this file.

The format is based on semantic versioning principles.

---

## v2.0.0 — 2026-08-08

### Added

- Operational Value Assessment Methodology v2.0.
- Industry-specific operational assessment profiles for Manufacturing, Healthcare, Transport & Logistics, Banking & Financial Services, Insurance, Energy & Utilities, AI & Digital Systems, and Other.
- Universal implementation-cost methodology.
- DDC network-requirement methodology.
- Versioned assessment configuration and reproducibility requirements.
- Executive PDF and JSON output requirements.
- Formal normative, informative, and conformance requirements.

### Changed

- Operational value and implementation economics are the primary assessment case.
- Investigation, dispute, review, and reconstruction value is treated as secondary.
- Business Value Assessment Methodology v1.0 is retained as a legacy historical specification.
